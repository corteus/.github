**Market before architecture.**  
**Tests and evals before autonomy.**  
**Deterministic control where deterministic control belongs.**  
**Human authority for consequential actions.**  
**Evidence after every run.**

We start with a business decision, define the evidence required to make it, and stop when the evidence does not justify continuing.
